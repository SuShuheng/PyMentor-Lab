# 原始 Python 材料覆盖审查

## 审查范围

`raw/知识库/Python语言程序设计` 中的 29 个 Markdown 文件和 126 张配图用于
教学覆盖面与常见题型审查。原始材料不是可追溯事实来源，不会写入
`source_ids`；正式来源仍只接受 `docs.python.org` 和 `peps.python.org`。

## 纳入结果

原材料第 1–8 章的入门、类型、结构化程序设计、组合数据、函数、文件、异常和
面向对象主题均已映射到正式 14 章体系。材料审查还暴露了九个原目录中较突出、
而首版 84 节点未单列的主题，本次补为正式节点：

- 标识符、关键字与命名；
- 进制、位运算与掩码；
- 对象共享与参数传递；
- 虚拟环境与依赖隔离；
- SQLite 持久化入门；
- `assert`、异常与测试职责；
- 封装、私有约定与多态；
- `robots` 规则与负责任抓取；
- 描述性统计入门。

扩展后仍为 14 章，共 93 个节点；每个新增节点同步生成误区、诊断题、练习题、
测试、掌握策略引用和 Python 官方来源。

## 有意不纳入 V1

- `eval`：不作为通识输入解析方式教授，避免把不可信输入直接执行为代码。
- `pickle`：不进入基础持久化主线，避免学习者对不可信数据形成不安全反序列化
  习惯；V1 使用 JSON 和 SQLite。
- Flask、Requests、BeautifulSoup、NumPy、Matplotlib：这些第三方生态主题适合
  后续应用轨道，但超出 V1 的 Python 官方文档/PEP 来源白名单。当前课程用标准库
  的虚拟环境、SQLite、`urllib.robotparser` 和 `statistics` 建立可迁移基础。
- 教材中的具体选择题答案和代码段：仅用于识别覆盖缺口，不复制到正式题库；
  正式题目由稳定模板生成并接受资产校验。

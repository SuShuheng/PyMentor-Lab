## Shared negative and ordering fixtures

`transport-contract-cases.json` is the single fixture source for both
Pydantic and Zod. It contains 21 request/result/error/Agent/sandbox/stream
accept-or-reject cases and two stream-order cases. Coverage includes:

- incompatible Worker and sandbox protocol versions;
- missing required identifiers and stable error fields;
- unknown boundary fields that could expose prompts, stacks, provider keys,
  reasoning, or host paths;
- stable error-code rejection;
- Agent node/proposal consistency and failed-run error requirements;
- valid stream events, invalid discriminants, and monotonic chunk ordering.

failure. It identified three real Pydantic/Zod disagreements: Zod silently
accepted unknown fields on Chat completion requests, stable error envelopes,
and SSE event variants while the Pydantic mirrors rejected them.

passed 14/14 after making the affected Zod objects strict. The owner validation
